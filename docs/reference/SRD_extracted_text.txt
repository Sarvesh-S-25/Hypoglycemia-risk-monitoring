1. Introduction
1.1 Purpose
This document speciﬁes the software (frontend + backend)
and hardware-interface requirements needed to build
GlucoSentry: a wearable ECG-based hypoglycemia risk
monitor with an adaptive, energy-aware controller and an on-
demand auxiliary foot-temperature check module.

3. Hardware ↔  Software Interface
3.1 Primary Node (ESP32) Responsibilities
Sample AD8232 output via ADS1115 at 250 Hz using a
hardware timer interrupt
Apply bandpass (0.5–40 Hz) + 50 Hz notch ﬁltering on-
device
Read MPU6050 continuously; compute a signal-quality
index (SQI) from motion magnitude

===== PAGE 4 =====
Reject/ﬂag windows below SQI threshold — do not
transmit them
Decimate ﬁltered signal to 100 Hz; buffer into 30–60 sec
windows
Transmit clean windows over BLE to host
Receive controller commands over BLE (mode change,
alert trigger, auxiliary wake) and act on them (adjust
sampling rate, drive vibration motor, forward wake signal
to auxiliary node)
Monitor AD8232 LO+/LO- pins; report leads-off state
3.2 Auxiliary Node (ESP32-C3) Responsibilities
Remain in deep sleep by default
Wake on BLE prompt from primary node/backend
Read both thermistors, compute bilateral ΔT
Transmit result (ΔT, validity ﬂag) over BLE
Return to deep sleep

7. Build Sequence (maps to locked
development plan)
1. ESP32 ﬁrmware: ADC sampling + ﬁltering + SQI, veriﬁed
via serial/logic analyzer before BLE is added
2. BLE link: primary node →  backend, raw window transfer
conﬁrmed
3. Backend inference: CNN+BiLSTM served via ONNX
Runtime, tested oﬄine on D1NAMO before live data
4. Controller: discrete mode state machine implemented
and tested against simulated risk/battery inputs
5. Auxiliary node: bring up independently, conﬁrm
wake/sleep/BLE cycle before integrating with controller
6. Frontend: build against mocked WebSocket data ﬁrst,
then connect to live backend
7. Full integration: live ECG →  risk →  controller →
alert/mode-change/foot-check-prompt, on real hardware
8. Evaluation: battery-life and false-alert-rate comparison,
adaptive vs. ﬁxed-rate baseline
8. Acceptance Criteria
